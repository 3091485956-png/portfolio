# Portfolio

个人求职作品集网站（React + Vite 构建）。

- 在线访问：https://3091485956-png.github.io/portfolio/
- 简历下载：https://3091485956-png.github.io/portfolio/resume.pdf

## 本地开发

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 产出 dist/（base=/portfolio/，适配 GitHub Pages 子路径）
```

## 部署

`npm run build` 后将 `dist/` 内容替换本仓库根目录并推送，GitHub Pages 自动发布。
